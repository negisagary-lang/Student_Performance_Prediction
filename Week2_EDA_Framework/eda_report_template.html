Quality checks to be performed on the real dataset include:

  • Missing values — identify and decide on treatment strategy.
  • Duplicate records — detect and remove.
  • Invalid values — range/logical checks (e.g., score > 100).
  • Outliers — detect using IQR / z-score, but do not auto-delete.
